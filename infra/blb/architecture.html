Key Differences from Original

Data Flow

CSV file (batch, offline only)
Shared memory ring buffer (real-time) + CSV (training)

Signal Type

Binary (0 or 1)
Rich: probability + rotation size + breakout score

ML Usage

Train model, extract thresholds, discard model
Train model, run model live on every tick

C++ Detector Role

Re-implements all 6 features + vote logic in C++
Thin reader — just reads signal from shared memory

Update Cycle

Retrain → manually update C++ thresholds → recompile
Retrain → drop new .pkl → restart scorer

Strategy (future)

Fixed parameters, no consolidation awareness
ML learns dynamic parameters from live signal data
