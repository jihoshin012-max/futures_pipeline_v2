========================================================================================================================
Config: LB=100, Inner=0.75, Outer=1.75, N=2
Data: NQ-250tick-calibration.csv (127567 bars)
Cost: $4.0/trade * qty, RTH: 09:30-15:45, ddof=0

Martingale logic:
  - Base qty = 1
  - Next trade qty = floor(1 * mult^consecutiveStops), capped at max
  - Per-side counters (same as circuit breaker)
  - Win resets counter to 0, loss increments
  - Daily reset, forced-opposite resets both counters
  - With N=2, counter can only be 0 or 1 when entering

Max daily loss logic:
  - Track cumulative PnL for current day (including costs)
  - When daily PnL <= -maxDailyLoss, flatten position and stop for day
  - Resets at start of each new trading day
  - $0 = disabled
