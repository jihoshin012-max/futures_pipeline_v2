Choppiness Filter — Visual Options v2 (real calibration data, first 80 bars)

Option A: Colored Bars (columns)

Each bar is independent — green below threshold, red above. No ambiguous connecting lines.

Below 0.10 (trade allowed) At/above 0.10 (blocked) — — Threshold (0.10)

Option B: Colored Bars + Dimmed Red Background

Same bars, plus subtle red wash behind blocked regions. Trade windows "clear" visually.

Green bar = allowed Red bar = blocked Red wash = blocked zone

Option C: Dots (no connecting lines)

Discrete points at each bar. Clean separation — no misleading line segments.

Below 0.10 At/above 0.10 — — Threshold

Option D: Split — Green Fill Below Threshold, Red Bars Above

Below-threshold bars are filled green rectangles anchored to zero. Above-threshold are thin red bars. Visually separates the two states.

Green fill = trade window Red bar = blocked — — Threshold

Option E: Colored Bars Capped at Threshold + Overflow Fade

Green bars drawn to full height. Red bars drawn to full height but with lower opacity above threshold to emphasize how far over. Threshold line is prominent.

Below 0.10 (full green) Above 0.10 (red) ━━ Threshold
