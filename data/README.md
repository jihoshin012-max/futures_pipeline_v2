# Data

Source market data. All workspace code reads from this directory.

**When you add or change a file in this directory, update this README.**

## Naming Convention

`[instrument]-[source]-[role].csv`

- **instrument** — market (NQ, ES, GC)
- **source** — what the data is (see source catalog below)
- **role** — ties to `_config/period-config.md` (calibration, holdout)

This convention is separate from the pipeline's `[arch]-[inst]-[type]-[status]`
pattern because data files are source material, not pipeline artifacts. They
don't have status progression and they don't move between workspaces.

## Source Catalog

| Source | What It Is | Consumed By |
|--------|-----------|-------------|
| `1tick` | 1-tick bars from SierraChart | Any archetype (C++ replay) |
| `250tick` | 250-tick bars from SierraChart | Any archetype (Python pipeline) |
| `10sec` | 10-second bars from SierraChart | Any archetype |
| `250vol` | 250-volume bars from SierraChart | Any archetype |
| `1day` | 1-day bars from SierraChart | Any archetype (calibration) |
| `zte` | Zone touch events from ZoneTouchEngine v4.0 (52 cols) | zone-touch |
| `ray-context` | Ray-touch pairs from ZTE, long format (7 cols) | zone-touch |
| `ray-reference` | RayValidator ground truth (10 cols) | zone-touch |
| `speedread` | SpeedRead V2 study log, 250-tick (from SC) | rotational |
| `regime-labels` | HMM regime labels (generated by hmm_regime_fitter.py) | Any archetype |

## Period Mapping

Roles are defined in `_config/period-config.md`:
- **calibration** = 2025-09-21 to 2025-12-14 (free for search and iteration)
- **holdout** = 2025-12-15 to 2026-03-14 (one-shot validation, frozen params only)

When the holdout window rolls, rename affected files to match
the new role assignment and update this inventory.

## Notes

- All CSV files are gitignored. Source of truth is SierraChart chartbook.
- Legacy `.txt` volume files and deprecated touch files (ZB4, ZRA) were
  not onboarded. They remain in the old pipeline if needed.
